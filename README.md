# PulseLounge

Basic scaffold with:
- Go web API
- React + TypeScript UI
- UI embedded into Go binary via `go:embed`
- Docker Compose with app + PostgreSQL

## API
- `GET /api/health`
- `GET /api/messages`
- `POST /api/messages`

Development setup, local run, Docker workflows, and hot reload instructions are in [DEVELOPMENT.md](./DEVELOPMENT.md).
